# Phase Commands

Use these sample prompts to quickly call, plan, execute, or review each phase.

## General Commands

- `$phase-workflow bat dau phase 01`
- `$phase-workflow trien khai phase 02`
- `$phase-workflow chia nho phase 03 thanh task`
- `$phase-workflow review ky thuat phase 04`
- `$phase-workflow kiem tra tien do phase 05`
- `$phase-workflow doc phase 06 va lap ke hoach`
- `$phase-workflow thuc hien phase 07 theo checklist`
- `$phase-workflow danh gia phase 08 da san sang release chua`

## Planning Commands

- `$phase-workflow lap ke hoach cho phase 01`
- `$phase-workflow doc phase 02 va de xuat thu tu implement`
- `$phase-workflow chia phase 03 thanh task 1-2 gio`
- `$phase-workflow cho toi roadmap nho de lam xong phase 04`
- `$phase-workflow liet ke dependency va rui ro cua phase 05`

## Execution Commands

- `$phase-workflow bat dau lam phase 01`
- `$phase-workflow trien khai phase 02 luon`
- `$phase-workflow thuc hien phase 03 tung buoc`
- `$phase-workflow code phase 04 theo file docs/phases`
- `$phase-workflow lam phase 05 nhung uu tien phan quan trong nhat truoc`
- `$phase-workflow hoan thanh phase 06 den muc MVP`

## Review Commands

- `$phase-workflow review ky thuat phase 01`
- `$phase-workflow review xem phase 02 co xung dot voi code hien tai khong`
- `$phase-workflow kiem tra phase 03 con thieu gi`
- `$phase-workflow danh gia phase 04 theo goc nhin san pham va ky thuat`
- `$phase-workflow review phase 05 va chi ra file nen refactor truoc`
- `$phase-workflow so sanh phase 06 voi codebase hien tai`

## Progress Commands

- `$phase-workflow kiem tra tien do phase 01`
- `$phase-workflow phase 02 da lam duoc bao nhieu phan tram`
- `$phase-workflow doi chieu code voi phase 03`
- `$phase-workflow cho toi danh sach viec chua xong cua phase 04`
- `$phase-workflow danh dau done in-progress blocked cho phase 05`

## Task Breakdown Commands

- `$phase-workflow tach phase 01 thanh checklist rat nho`
- `$phase-workflow chia phase 02 thanh task theo thu tu phu thuoc`
- `$phase-workflow bien phase 03 thanh checklist de code tung buoi`
- `$phase-workflow tach phase 04 thanh task foundation implementation verification cleanup`
- `$phase-workflow tao task list cho phase 05 de toi lam trong 2 ngay`

## Natural Vietnamese Prompts

- `bat dau phase 01`
- `lam phase 02 cho toi`
- `chia nho phase 03 thanh task`
- `review ky thuat phase 04`
- `kiem tra tien do phase 05`
- `phase 06 nen lam gi truoc`
- `doc phase 07 va trien khai phan quan trong nhat`
- `phase 08 da du dieu kien release chua`

## File-Based Commands

- `doc file docs/phases/phase-01-foundation-state-and-schema.md va bat dau lam`
- `dua tren docs/phases/phase-02-service-detail-and-project-flow.md hay lap ke hoach`
- `review docs/phases/phase-03-backup-import-export-and-workspace-safety.md`
- `thuc hien theo docs/phases/phase-04-search-filter-and-navigation.md`
- `doi chieu codebase voi docs/phases/phase-05-secret-health-and-security-hardening.md`

## Suggested Usage Pattern

1. Start with planning:
   - `$phase-workflow lap ke hoach cho phase 01`
2. Break into tasks:
   - `$phase-workflow chia phase 01 thanh task 1-2 gio`
3. Execute:
   - `$phase-workflow trien khai phase 01`
4. Review progress:
   - `$phase-workflow kiem tra tien do phase 01`
5. Review technically:
   - `$phase-workflow review ky thuat phase 01`
